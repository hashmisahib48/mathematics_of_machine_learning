The Mathematics of Machine Learning -- Solutions Manual, Volume I: solution programs
Dr. Mudassar Hussain Hashmi

solutions/chNN/code/    the programs behind every solution (hand checks, class B programs, question numbers); run_all.sh reruns them all
solutions/chNN/verify/  the outputs those programs printed, quoted in the manual
solutions/chNN/fig/     scripts that draw the solution figures and illustrations
Some scripts import the textbook's own chapter code (the chNN/code folders of this volume, one level up).
Tested with Python 3.13, scikit-learn 1.9.1, NumPy 2.5, SciPy 1.18, Matplotlib 3.11, pandas 3.0. Timings depend on the machine.
