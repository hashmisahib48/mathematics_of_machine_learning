# The Mathematics of Machine Learning

**An Illustrated Guide to Every scikit-learn Algorithm** · Dr. Mudassar Hussain Hashmi

Companion code for the three-volume book series. Every program listing in the books is here with its exact printed output, together with the scripts that draw every figure and the programs behind every solution in the Solutions Manuals. Everything in this repository is free.

| Folder | Volume | Chapters |
|---|---|---|
| [`Volume_I`](Volume_I) | Foundations and Linear Models | 1–19 |
| [`Volume_II`](Volume_II) | Kernels, Trees, Ensembles and Neural Networks | 20–35 (and the refresher, `ch00`) |
| [`Volume_III`](Volume_III) | Unsupervised Learning, Data Preparation and Model Selection | 36–59 (and the refresher, `ch00`) |

## Layout of each volume

```
Volume_X/
  chNN/code/     the programs of the listings of Chapter NN
  chNN/verify/   the outputs those programs printed, and the numbers behind the figures,
                 worked examples and problem answers (.json)
  chNN/fig/      the scripts that draw every figure, equation image and problem illustration
  lib/           shared figure style and equation renderer used by the fig scripts
  solutions/     the solution programs of the volume's Solutions Manual (same chNN/code, verify, fig layout)
```

Run a program from inside its own folder, for example:

```bash
cd Volume_I/ch09/code
python3 ols_scratch.py
```

Each `verify` folder holds what the program printed when the book was made, so you can compare your output line by line.

## Requirements

The programs need Python 3.11 or later with scikit-learn, NumPy, SciPy, Matplotlib and pandas.
The books were produced with **Python 3.13, scikit-learn 1.9.1, NumPy 2.5, SciPy 1.18, Matplotlib 3.11 and pandas 3.0**. To install the same release:

```bash
pip install scikit-learn==1.9.1 matplotlib pandas
```

Later releases run the programs as well, but they may print a warning where an argument is about to be removed, or differ in the last digits. All data sets ship with scikit-learn or are generated by the programs, so no download is needed.
