# Mathematics of Machine Learning Algorithms

Companion files for *Mathematics of Machine Learning Algorithms* (Level A of the Machine Learning series), by Mudassar Hussain Hashmi. ISBN 9798142692863.

Every program listing in the book is here, together with the output it printed and the scripts that draw the figures. The programs use Python, NumPy, SciPy, pandas, Matplotlib, statsmodels and scikit-learn; the versions are listed in Appendix A of the book.

## Layout

```
chNN/code/     the programs of the listings of Chapter NN
chNN/verify/   the outputs those programs printed, which are the printed numbers of the chapter
chNN/data/     small data files used by the programs, where a chapter needs them
chNN/fig/      the scripts that draw the figures of the chapter
```

Run a program from inside its own folder, for example:

```bash
cd ch03/code
python3 linreg.py
```
